# Robot sprites

Six 64×64 RGBA pixel-art states: `idle`, `blink`, `point-right`, `think`,
`success`, `done`. Generated by the author with Gemini (Nano Banana Pro)
from the brief in `../../MASCOT.md` on 2026-09-23, then normalized here:
snapped to the native 23-px grid of the generations, magenta background
keyed to alpha, quantized to a shared 9-color palette with the accent
pinned to Stevinator burnt orange `#C44D2B` (lit `#F28C4A`, dim `#7A3E2E`),
head-anchored so all states line up, stray JPEG pixels removed.
Owned by Stevinator; no third-party assets.
